# MasterMonk 3.2.0 screenshot provenance

These images were captured by the project owner from a running MasterMonk 3.2.0 instance on 8 September 2026. They show the application’s real interface populated by the public-source catalog saved by that instance; they are not mockups or simulated product screens.

Catalog counts, source timestamps, CVE examples, scores, and change totals are accurate to the captured instance at that moment. They are not bundled application data and should not be read as current values for another installation or later date.

The images contain only public vulnerability evidence and local-loopback example URLs. They do not contain an administrator setup code, password, API key, session token, private manifest, or runtime database.
