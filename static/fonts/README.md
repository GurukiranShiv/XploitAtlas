The full fonts include their original character coverage; no conversion or subsetting was performed. Intrinsic font names are retained. CSS maps the shipped regular and semibold Sans weights, regular and medium Serif weights, and regular Mono weight to the interface. Other characters can fall back to the user's system fonts.
